# TruthTrace Palette 5 UI

The interface uses Palette 5 as the visual foundation:

- `#E2DBBE` — warm cream, used sparingly for soft highlights / warning-adjacent surfaces
- `#D5D6AA` — muted olive-sage, used for borders and quiet structural accents
- `#9DBBAE` — muted sage, used for positive/secondary states
- `#769FB6` — dusty blue, used for charts and secondary accents
- `#188FA7` — signature teal, used for primary actions, active states and key links

The application remains predominantly white with charcoal text. Saturated colors are reserved for semantic states and important controls.
